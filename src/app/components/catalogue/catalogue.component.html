Kies je volgende bouwavontuur

Van een imposant kasteel tot een technisch meesterwerk, van een ruimteschip tot een kleurrijk Disney-model: in onze catalogus vind je LEGO-sets voor verschillende leeftijden, interesses en bouwervaringen.

Iedere set wordt zorgvuldig gecontroleerd voordat hij opnieuw wordt verhuurd, zodat jij met een complete set aan de slag kunt.

Twijfel je welke set bij jou past? Kijk dan niet alleen naar het aantal steentjes. Bedenk vooral wat je leuk vindt: een uitdagend bouwproject, samen bouwen met de kinderen, lekker spelen na het bouwen of juist een prachtig model om een tijdje tentoon te stellen. Bij iedere set beschrijven wij onze persoonlijke ervaring bij het bouwen, zodat je een weloverwogen keuze kunt maken.

En het mooiste? Je hoeft niet te kiezen welke set je voor altijd wilt houden. Bij Valley Road Bricks kun je ze gewoon uitproberen.

Bekijk de collectie en kies jouw volgende set.
